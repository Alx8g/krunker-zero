# Provenance and boundaries

Created as a new local Git repository named `krunker-zero` in this session. Source
implementation and fixtures were written here from the stated goal and public
engine/platform interfaces. No existing client implementation was used.

The excluded Wok repository, source, docs, history and prior implementation notes
were not opened, searched or imported. This project rule is retained in AGENTS.md.
No game source or assets were supplied in this conversation, copied into this
repository, or executed during validation. The sample `needs-dom.js` is original
synthetic test code, not a quoted or extracted Krunker callsite.

The connected GitHub toolset was inspected for repository creation. It exposes
file/commit operations for existing repositories, but no repository-create action.
Plugin discovery exposed no additional available repository-create action. No
existing user repository was read or modified. This is a **local repository**,
not a claimed newly published GitHub repository.

A QuickJS source download was attempted from its official release URL and failed
because outbound networking/DNS was unavailable. No source was extracted or used.
The V8 embedding test instead uses the installed Node headers and engine through
an explicitly development-only adapter. The engine bytes are not redistributed.

These are factual project process notes, not a legal certification. Original game
code/assets remain separately licensed. This repository does not grant rights to
distribute them. No license was chosen on the user's behalf for this new codebase.
