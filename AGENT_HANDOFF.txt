Use branch fix/windows-native-acceptance, not main. Main retains the original untested v0.4 handoff. Read AGENTS.md first. Its independent-implementation exclusion remains absolute. Earlier validation and LOCAL_AGENT_HANDOFF.md are historical starting-state documents, not the current Windows result.

The native Windows runtime works in tested fixtures. Krunker is not playable. No complete game bootstrap, menu, login, match, audio, asset pipeline or networking acceptance is claimed.

- Core and graphics own-child module/import audits passed.

- Physical keyboard/raw mouse, capture release, minimize/restore and multiple DPI settings remain UNVERIFIED. The demo recorded zero raw mouse events.

Changes
- tools/windows_deps.py supplies a managed Git launcher, invokes pinned GN/Ninja Python entry points with the validated interpreter, passes GN's script interpreter explicitly, forwards the custom VS 2022 installation path and limits dependency sync to two jobs.
- SDK 28000 was installed alongside SDK 26100. The pinned ANGLE source requires SDK 10.0.28000.0. Doctor still does not check component-specific SDK versions before downloads.
- native/win32_window.cc corrects small captioned-window buffer sizing. Requested 64x64 had become 120x64. Post-creation SetWindowPos with SWP_NOSENDCHANGING passed the unchanged fixtures. native/graphics.cc now reports requested and actual sizes on mismatch.
- runtime/core.js implements URLSearchParams in the optional core profile. Six new native tests cover representative query semantics. This is not exhaustive WHATWG conformance. Bare profile still lacks the API.

Private game capture and unchanged probe
A fresh capture obtained 33 network response bodies and 123 compiled-source snapshots with zero collector issues. Every saved hash was checked. This does not establish complete asset coverage or execution order for every snapshot.
The selected initial parser order is first inline timestamp assignment, frvr-sdk.min.js, then frvr-channel-web.min.js. The HTML script tags established this order. The inline source is a CDP compiled-source string, not original HTTP wire bytes. Network text bodies are also CDP UTF-8 reencodings. Do not treat eval snapshots as independent scripts.
Input SHA-256 records are retained in the private probe reports. These files and the capture are deliberately NOT in GitHub.
The first inline timestamp script and FRVR SDK completed in the standalone core host. Adding the channel script first failed on URLSearchParams. After implementation, the same ordered, hashed copies advance to ReferenceError: document is not defined. The failing channel detection constructs a context containing query, document, location and buildTimePlatform. Location is also absent. Do not invent placeholder document/location objects to hide this failure. Establish the actual page-context operations and input semantics before implementing the next contract.
